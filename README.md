# FireDNG – Installer und Updates

CinemaDNG-Importer für Adobe Premiere Pro (Sigma fp / Pixboom Spark) von Hot Media Haus.

Hier liegen nur die fertigen Installer. Neueste Version: **Releases** rechts → `FireDNG-<Version>.dmg` laden, öffnen, "FireDNG installieren.pkg" starten.

Installierte Plugins prüfen hier automatisch auf Updates (signierte `latest.json`).
